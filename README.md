# Java Configurable Matching Engine (MoteurDeMatching)
Core Java matching engine implementing configurable criteria scoring and automated entity pairing.
## Features
- Multi-Criteria Scoring: Configurable criteria scoring for automated entity pairing.
- Extensible Object-Oriented Design: Strategy & Filter patterns.
- Deterministic Ranking: Consistent and predictable criteria evaluation.
- ## Tech Stack
- Java JDK 17+, OOP
- ## Compilation & Execution
- javac -d bin src/**/*.java && java -cp bin Main
